# 快捷指令记账

按用户偏好，以直接后台记账为主入口，参数齐全时不打开 App、不要求再次确认；预填页面保留为可选动作。当前已接入 App Intents 代码，支持普通支出、收入和同币种转账。Windows 核心测试已通过；Apple SDK 编译、系统动作发现、后台执行及签名安装后的真机体验尚待验证，旧版 IPA 不包含本次改动。

## 动作与参数

| 动作 | 行为 |
|---|---|
| 直接记一笔（主要入口） | 使用配置的参数直接保存，不打开确认页。成功返回流水 UUID 文本，供后续步骤使用；失败返回中文错误。系统“用 Ledger 记一笔”采用此动作 |
| 准备记一笔（可选） | 打开 Ledger，预填普通记账页，用户保存后入账。金额、分类等可留空后补 |

两者支持类型、金额、账户、二级分类、转入账户、主体、日期、标题和备注。默认类型为支出；未指定账户或主体时使用账本默认值，日期留空采用运行时刻。账户决定币种。

金额按文本传入，例如 `28.50`，使用精确整数解析，不经过 Double、不自动四舍五入。必须大于零、最多两位小数；不接受算式、千位逗号、币种符号或科学计数法。准备动作可以完全不提供金额。

直接保存还要求：支出／收入选择对应的有效二级分类；转账选择转入账户，两端账户不同且币种一致，转账不填收支分类。没有默认账户时必须明确选账户。缺少金额、分类、转入账户或必需的账户时，在快捷指令中请求补充；自动化需要预先配置完整参数。已停用或已删除的选择会报错，不按同名项自动替换。

## 配置示例（待新版本安装验证）

在系统“快捷指令”新建快捷指令，添加 Ledger 的动作：

1. 日常午餐：选择“直接记一笔”，类型支出、账户微信、分类餐饮下的对应二级分类、标题午餐；金额使用前一步的输入。参数齐全后后台保存。
2. 固定停车费：选择“直接记一笔”，金额 `10.00`、类型支出，明确选择账户和停车对应分类。每次运行新增一笔。
3. 钱包转入银行卡：选择“直接记一笔”，类型转账、指定转出与转入账户、金额，分类留空。

配置后可通过系统快捷指令入口运行；Siri 短语、动作按钮及个人自动化的具体入口和权限以真机系统为准。当前不包含账单识别、读取其他 App 的支付数据、贷款、投资或批量导入动作。

## 草稿、保存与重试

- “准备记一笔”不会立即改账。已有草稿先询问是否替换，取消保留旧草稿。安装新草稿成功后沿用普通自动草稿及保存流程。
- 正在编辑流水、账户、设置或筛选时，等待已有页面关闭再展示请求；同时只保留一笔待确认请求，第二笔会明确报错。尚未安装为普通草稿的请求仅留在内存，进程被终止后需重新运行。
- “直接记一笔”保留手动草稿及草稿序号，成功后更新 App 内余额和流水。它与页面共用同一个 Repository，不创建另一份账本，也不使用单独扩展或 App Groups。
- 每次运行创建新的操作 ID。同一内部请求重试走已有防重规则；用户重复运行整个快捷指令代表新的记账，不凭金额、日期或标题合并。此机制不等于第三方账单去重。
- 正在保存或恢复时返回忙碌提示；引用、金额或事务校验失败不修改余额和旧草稿。入账内容进入原有 SQLite 和 CSV ZIP 备份，无新增数据格式。

下一次 Apple 验证须完成：

- 编译 App Intents 元数据，确认系统可发现两个动作，账户／主体默认值、分类方向及改名停用后的选择行为正确。
