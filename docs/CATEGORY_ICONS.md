# 分类图标实现与验证

日期：2026-09-27。范围为分类图标库、选择与回退，不包含分类颜色、排序、标签项目或使用指南页面；预算按用户要求延期。

## 当前行为

- 设置 → 分类管理 → 新增／编辑分类 → 图标。一级和二级共用入口，提供 **84 个 SF Symbols、10 个主题**，可按中文名称、关键词、英文词和符号名搜索。多词全部匹配，主题与搜索同时生效；结果保留目录顺序，无匹配时明确显示空状态。
- 点击结果只改变当前图标页预览；“使用图标”返回分类编辑，“取消”丢弃本页选择。分类编辑仍须保存；取消分类编辑会丢弃名称、图标和恢复默认等所有未保存的改动。
- 恢复默认通过分类 UUID 查内置种子映射，改名不会丢失默认。自建分类回到通用 `tag`，不会因名称类似内置分类而套用默认。修改一级图标不修改二级图标。
- 目录仅提供当前系统实际可用的符号；恢复的旧符号不在图标库中但系统支持时仍照常显示。系统不支持时用 `tag` 显示，原字符串不被静默改写，编辑入口显示“暂用通用图标”。
- 分类管理、首页及流水使用同一显示组件：单色、20 pt Regular、28×28 pt 图标位；原生分类菜单保留系统 `Label` 和尺寸，复用同一符号可用性／回退函数。不把分类名和卡片染色，不用图形替代名称。未知符号解析使用上限配置为 256 项的缓存，不无限累积外部备份中的任意标识。
- 100 项新账本目录的 UUID、顺序和数量保留；新默认名为“购物”“数字服务”，数字服务默认应用窗口图标，车辆养护使用线性维修工具。已有数据库打开、备份恢复不重新播种，不覆盖旧名称、图标、停用状态或用户排序。

## 文件与数据

| 文件 | 作用 |
|---|---|
| `Sources/LedgerCore/CategorySymbolCatalog.swift` | 符号、中文名称、主题、检索关键词及稳定 UUID 默认查询 |
| `Sources/LedgerCore/SeedCatalog.swift` | 100 项内置分类及新账本默认值 |
| `App/CategorySymbolView.swift` | 系统可用性与回退、统一图标显示、搜索选择及本页预览状态 |
| `App/CatalogViews.swift` | 分类管理入口、编辑保存与独立恢复默认 |

继续保存现有 `Category.symbol`，没有新增业务字段，SQLite schema 3 与 CSV profile 3 不变。旧 profile 1／2／3 都有该字段；图标库元数据是随 App 发布的离线资源，不替代用户保存的选择，也不额外写入用户账本。旧符号原文经备份导出、恢复后保持。
