# 标签与项目

更新：2026-09-27。本批代码已实现，Windows Core 已验证；GRDB、SwiftUI 和模拟器回归仍待 Apple 构建恢复后执行。预算继续延期。

## 使用与规则

- “账户 → 设置 → 标签管理／项目管理”可新增、改名、停用标签、归档项目以及重新启用。当前不提供物理删除、合并或批量改历史。
- 记账和编辑流水在“更多信息 → 标签／项目”中选择零到多个标签、零或一个主项目。支出、收入、转账、退款、出售回收均可关联；分类、主体、金额和账务计算不因关联而改变。
- 项目适用于旅行等跨分类聚合，餐饮仍归餐饮，交通仍归交通。稳定 UUID 关联不拼入标题或备注；改名、停用、归档不重写历史流水。
- 已停用标签／归档项目不供新流水选择。编辑旧流水可保留原有关联，也可清除；复制仅保留可用的关联，原流水不变。“保存并继续”清空标签和项目，避免上一笔项目自动带到下一笔。
- 未完成草稿保留缺失／停用引用，保存时再次校验；选择页能清除缺失标签、重选项目。关闭选择页只返回草稿，流水仍需点保存；编辑旧流水放弃修改不入库。
- 流水列表用次级文字显示项目与标签，详情显示名称及归档／停用状态。继续采用中性背景与现有字号体系，本批不重做卡片配色。
- 筛选可组合项目、标签与现有其他条件；其他条件间为 AND。标签支持“全部匹配／任一匹配”，没选标签时不限制。停用标签和归档项目仍可查；结果按原稳定顺序分页，同笔多标签不会产生重复行。筛选仍为临时页面状态，不是持久配置。

## 数据和恢复

`EntryTag`、`EntryProject` 进入 `LedgerBook`；流水和草稿增加 `tagIDs`、`projectID`。旧 JSON 缺失新增字段时分别读为空数组／nil，不改写旧载荷。新建与编辑的操作防重包含这些字段，失败不消耗草稿修订号。

SQLite schema 4 新增 `tags`、`projects`、`entry_tags` 和流水的 `project_id`。标签关联表含外键、同一流水标签唯一键和顺序；读取核对它与载荷的一致性。整本读取一次查询全部关联，不逐条额外读表；分页只核对返回页。普通新增／编辑在原事务内更新目标流水及关联，整本恢复和目录维护保留原事务语义。旧 schema 1／2／3 同事务迁移，打开校验失败时回滚结构和版本。

CSV profile 4 共 16 个文件，新增标签、项目、流水标签关联、草稿标签关联；所有配置状态与关联进入校验和／行数／字段字典。精确接受 v1／v2／v3 旧契约，恢复后新维度为空；v3 退款关联和净回收开关照常保留。拒绝混搭文件、重复关联、正式流水悬空引用；草稿仍按软引用保留待修复输入。详细契约见 [CSV_FORMAT.md](CSV_FORMAT.md)。

现有每表十万行的备份上限也适用于关联表，一笔多标签会占多行；大账本容量与十万笔性能仍待独立优化，不宣称已达标。
