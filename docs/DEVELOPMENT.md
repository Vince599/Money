# 开发记录

日期：2026-09-26，更新至第三批代码。产品基线：[设计 v1.3](../IOS_DESIGN.md)；本记录区分代码实现与实际验证，不将基础账本标为全量交付。

## 本批已写入代码

| 范围 | 当前行为 |
|---|---|
| 金额 | 现金以 Int64 最小单位保存，解析与运算不用 Double；检查精度、币种和溢出 |
| 基础账本 | 支出、收入、同币种转账；资产与负债方向区分；内部生成平衡分录计算余额 |
| 历史实账 | 期初之前的支出也正常扣当前余额；余额更正独立记录差额，不计消费或收入 |
| 账户 | 创建钱包、银行卡、现金、储值、信用卡，设置期初与汇总范围；储值默认不纳入；默认记账账户可选 |
| 资料维护 | 账户改名、停用及汇总开关；分类／主体新增、改名、启停，分类图标可选；默认主体可设；历史记录保留 |
| 分类目录 | 新账本普通中文种子共 100 项（20 个一级、80 个二级），保留已有 ID；已有账本的用户目录不被覆盖 |
| 流水修改 | 编辑保留事件身份和创建时间、检查版本；删除撤销影响；旧操作 ID 保留防重标记 |
| 记账输入 | 收支与转账切换保留公共字段，各自分类保留；一份自动草稿；保存及保存并继续 |
| 金额计算器 | 四则运算、括号、标准优先级、清除退格；精确有理数中间运算，仅最终按分四舍五入并提示；表达式随普通草稿保存，正式流水只存计算结果 |
| 流水查找 | 标题／备注字面搜索；方向、转账双端账户、一级／二级分类、主体、币种、金额上下限和发生日期组合筛选；停用资料仍可查询历史，无结果与空账本分开显示 |
| 复制流水 | 新身份、新操作 ID、默认当前日期；先建立草稿，覆盖旧草稿须确认；停用账户与分类待重选，有效主体回退；原记录不变 |
| 保存一致性 | 正式入账、草稿更新同事务；序号保护延迟请求；失败保留旧数据库状态和输入 |
| SQLite | 规范化核心列、精确整数金额、外键、操作唯一约束；完整模型载荷与关键列互相核验；拒绝未知版本和坏库 |
| CSV ZIP | `ledger-core-v1` 固定 12 份 CSV，包含本版全部核心字段、设置、草稿和退役操作 ID；字段字典、计数与原始字节 SHA-256 随包保存 |
| 恢复 | 系统文件选择 → 校验与摘要 → 用户确认 → 原账本安全 ZIP → 同一 SQLite 事务替换账本／设置／草稿；旧草稿请求隔离；安全副本可导出或再恢复 |
| 页面 | 首页、流水、账户、记账、短详情、余额更正的 SwiftUI 基础页面；无示例资产注入 |
| 工程 | Swift Package、XcodeGen、固定工具配置、手动 GitHub Actions、模拟器测试及未签名 IPA 脚本 |

数据库读写通过单一 Repository actor 协调，避免多个旧账本快照互相覆盖。提交操作 ID 与编辑版本承担不同职责：前者防重复，后者防旧版本覆盖。余额更正重试沿用已存日期，即使重开数据库也不重复记账。外部文件在安全访问期间协调读取；恢复提交成功后直接返回已验证快照，避免后续读取失败被误报为恢复失败。

## 当前限制

- 当前已形成基础账本链路；原生 UI 的字号、双列卡片、对齐、大字号和深色仍待专项检查，尚未复刻最终首页。暂为三个功能页，最终自定义底栏与投资摘要仍在计划中。
- 云端运行 #4 的首页、账户和备份截图已检查：当前合成数据下文字与控件可见，无重叠截断；这只是基础原生页面，不代表最终视觉验收。长名称、大字号、深色及不同屏幕尺寸仍须专门验证。
- 云端运行 #9 的新增计算器、复制后搜索截图已检查：算式／金额及两笔流水可见；编辑算式时收起自带按键，结束输入后使用自带按键，确认按钮固定在可见区域。第三批还修复了容器无障碍标识覆盖子控件的问题，并按原生半屏滚动和搜索关闭控件完成页面测试。
- 分类目录已包含普通中文种子；自定义颜色、排序、英文名和按需扩展模板待实现。分类移动／合并／删除须后续补影响预览，当前维护入口不提供这些操作。正式新账本没有示例资产和流水。
- 现金支持 CNY／HKD／USD 各两位小数；跨币种转账、汇率换算、证券价格和数量尚未实现。首页资产分币种列出，当前月消费只显示人民币。
- 本批计算器、基础搜索筛选与复制已实现；标签项目、来源／状态／关联筛选、常用筛选保存、来源账单导入和每日分类汇总待后续补齐。筛选目前是页面内临时条件，不作为持久配置保存。
- 数据库存储采用整本事务保存，读取含完整校验；用于小规模初始验证，尚未达到十万笔的性能目标。增量写入、索引查询和分页需后续实现并测量。
- 本版核心备份／字段字典已实现；仅接受自身支持的 profile、格式和数据库版本，未知版本明确报错，未来业务模块必须同步扩展契约与迁移。ZIP 使用无压缩 stored；暂不接受第三方重新压缩或加密，单 CSV 32 MiB、总 CSV 64 MiB、单表最多十万行、单字段 1 MiB。数据库与 Repository 恢复集成已通过，用户反馈此前版本在 iOS 27 上经系统“文件”导出并恢复 ZIP 成功；第三批算式／复制草稿的真机恢复尚待验证，P1 尚未全部完成。
- 贷款、报销借还、预算、投资日终、物品订阅、图表、NAS／iCloud、Widgets、中英文完整适配均未完成；已确认需求继续保留。
- `Package.swift` 固定 GRDB 7.11.1；已提交云端真实解析生成的 `Package.resolved`，固定修订为 `b83108d10f42680d78f23fe4d4d80fc88dab3212`。后续 Windows 核心测试不得用不含 Apple 依赖的解析结果替换此锁。
