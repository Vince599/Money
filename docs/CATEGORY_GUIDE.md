# 使用指南 · 账单分类怎么选

本指南提供日常流水的默认分类口径，供后续在 **设置 → 使用指南 → 分类说明** 中展示。包含分类范围、应包含和排除的内容、典型例子，以及容易混淆时的选择规则。正文面向使用者；页面与数据实现要求维护在 [分类附录第 1.4 节](../IOS_CATEGORIES.md#14-分类说明与使用指南)。本轮完成文档，尚未实现 App 指南页面。

## 1. 先看什么，再选分类

1. **先看流水性质。** 自己账户间转账、还款本金、储值充值、借还本金、报销回款不是普通收入或消费。退款或回收先看能否关联原购买。
2. **再看买了什么，或钱为什么收到。** 平台、品牌、商户名称、付款周期及付款账户不决定用途。运动品牌的衣服仍是衣服，按月付款的健身卡仍是健身服务。
3. **交叉项目按下表的固定边界选择。** 服装鞋包、数码设备、医疗器械等有明确物品边界时，使用对应专类；明确赠送的礼物使用赠礼分类。不要让同一件东西因某次使用场景不同就来回换类。
4. **普通流水只选一个二级。** 已分别形成实际扣款或到账的记录按各笔用途选择。单笔组合收支优先使用指南已明确的规则，例如工资和奖金合并到账默认归工资；其余单笔组合消费按金额占比最高的已知子项归类，金额相同时按主要购买目的，备注补充内容。确实无法理解用途时保留待分类，不用“其他”表示“我不知道”。贷款、投资中本金和费用的业务拆解不适用这条普通流水规则。

分类用于保持前后统计一致，不存在唯一适用于所有人的划分。下面是本账本的默认口径；如果你希望用另一套规则，应先明确规则，再持续使用，不逐笔临时摇摆。自定义目录和已记账历史不会因为阅读指南而自动改变。

## 2. 运动衣与健身房怎么分

| 实际购买内容 | 默认归属 | 选择理由 |
|---|---|---|
| 运动 T 恤、瑜伽裤、泳衣、运动外套 | 购物／服饰鞋包 | 购买的是服装，不因穿去运动而改类 |
| 跑鞋、篮球鞋、运动袜、运动包 | 购物／服饰鞋包 | 服装、鞋、包采用统一归属 |
| 健身房月卡、年卡、单次入场 | 休闲运动／运动健身 | 购买的是运动场馆使用服务 |
| 私教、瑜伽课、游泳教学 | 休闲运动／运动健身 | 以运动实践和训练为目的的课程统一归运动健身 |
| 哑铃、瑜伽垫、球拍、篮球、非数码训练器材 | 休闲运动／运动健身 | 属于非服饰、非数码的运动器材 |
| 运动头盔、护膝等运动防护器材 | 休闲运动／运动健身 | 运动防护用品；作为医疗矫治器械购买的用品归医疗器械 |
| 跑步用的智能手表、运动手环 | 数码设备／智能与穿戴 | 智能设备归数码，运动场景不改变物品性质 |
| 健身时使用的耳机 | 数码设备／音频设备 | 按实际设备类型归类 |
| 体育赛事门票 | 休闲运动／文娱活动 | 观看活动，与自己参加训练、使用场馆区分 |
| 为朋友专门购买并赠送的运动衣 | 人情往来／礼物 | 明确赠礼目的优先；普通替家人付款仍按实际用途与主体记录 |
| 给健身房储值账户充值，按每次到店扣余额 | 储值转账；扣费时归运动健身 | 充值与实际消费分开，避免同一笔钱重复算支出 |

按月、按年购买服务期限固定的健身会籍，在实际付款时归运动健身，并可关联订阅周期；它不会仅因“预先付钱”就自动成为按余额扣款的储值账户。

如果以后想看“一共为健身花了多少钱”，可用同一个运动项目或标签汇总服饰、器材和课程，不必改变它们的基础分类。

## 3. 其他常见交叉项目

| 场景 | 默认归属与排除规则 |
|---|---|
| 外卖咖啡、外卖饭菜 | 单独咖啡归饮品，饭菜归外卖；配送方式不覆盖已经明确的饮品用途 |
| 咖啡豆、咖啡杯、咖啡机 | 做饮品的原料归食材，杯子归厨具餐具，咖啡机归家用电器 |
| 纸巾、洗衣液、洗衣服务 | 前两项归日用品，服务归家政洗护 |
| 护肤品、理发美容服务 | 护肤商品归美妆护理，服务归美容理发 |
| 冰箱、智能扫地机、智能手表 | 家电整机归家用电器，智能手表归智能与穿戴；带“智能”两个字不等于全部归数码 |
| 手机、手机维修、手机壳 | 分别归手机平板、维修服务、数码配件；维修可关联原物品成本 |
| 电脑内部 SSD、独立移动硬盘、云盘、宽带 | 分别归电脑配件、网络与存储、云服务与存储、宽带 |
| 小说、教材、电子书、报刊资讯会员 | 单本或成套书籍（含小说）统一归图书资料，不按阅读目的反复区分；持续新闻资讯内容服务归内容资讯 |
| 摄影器材、摄影课程、健身课程 | 分别归摄影设备、课程培训、运动健身；知识技能培训与运动训练使用已明确边界 |
| 游戏购买、游戏内消费、影音会员 | 前两项归游戏，影音会员归数字服务／影音会员；游戏平台与支付周期不改变用途 |
| 旅行机票、酒店、门票 | 分别归机票、住宿、景点门票，通过旅行项目汇总 |
| 牙科治疗、独立体检、药店买药、血压计 | 分别归门诊住院、检查体检、药品、医疗器械；成套诊疗费不强制拆单 |
| 普通衣鞋、训练器材、医疗矫治器械 | 分别归服饰鞋包、运动健身、医疗器械，以购买项目的实际性质判断 |
| 工资中的交通津贴、年终奖、实报实销回款 | 分别归工资、奖金、报销结算；转账附言写“补助”不代表都归补助 |
| 兼职接单、经营销售、客户归还垫付款 | 分别按劳务报酬、经营收款、往来结算判断，不能只根据付款人是客户就统一记经营收入 |
| 银行利息、证券分红、借款人还本付息 | 分别归存款利息、投资事件、本金往来结算＋借出利息；不能把本金一起算收入 |
| 赠与红包、朋友借款、AA 代垫收回 | 分别归收礼、借入、代垫结算；“收到转账”只说明到账，不说明性质 |

退款、二手出售、返现、理赔等收入侧边界，详见 [收入与流入说明](CATEGORY_INCOME_GUIDE.md)。已关联原购买的回收沿用现有规则：保留原消费金额，回收单列，详情展示净花费，不释放原预算。

## 5. 按需扩展分类说明

下面四组只在需要时启用，不增加基础 100 项。启用模板后，相同用途统一使用模板中的细项；未启用时不要自动代用户新建。二级对应的图标维护在分类附录，说明与图标使用同一模板身份。

### 宠物

范围：为宠物专门购买的食物、医疗、用品和服务。不包含人的食物与医疗；普通家居清洁不因为家里有宠物就全部改归宠物。

| 二级 | 包含 | 不包含及应归哪里 | 例子 |
|---|---|---|---|
| 食品 | 宠物主粮、零食、专用营养食品 | 人吃的食品按餐饮细项；兽医治疗用药归宠物／医疗 | 猫粮、犬用零食 |
| 医疗 | 宠物诊疗、疫苗、治疗药品和医疗护理 | 人的诊疗归医疗健康；日常美容归宠物／服务 | 宠物疫苗、兽医门诊 |
| 用品 | 宠物专用玩具、猫砂、牵引绳、窝和服装 | 宠物食品、医疗、服务分别归对应细项 | 猫砂、宠物牵引绳 |
| 服务 | 宠物洗护、美容、寄养等服务 | 宠物诊疗归医疗；为自己洗衣归生活服务 | 宠物美容、假期寄养 |

### 育儿

范围：婴幼儿专用喂养、育儿用品和托育。不把孩子的全部消费归到育儿；一般衣鞋、医疗、教育仍按对应用途，孩子作为主体记录。

| 二级 | 包含 | 不包含及应归哪里 | 例子 |
|---|---|---|---|
| 喂养 | 婴幼儿奶粉、专用辅食及喂养食品 | 家庭普通食材归餐饮／食材；奶瓶器具归育儿／用品 | 婴儿配方奶粉、专用米糊 |
| 用品 | 纸尿裤、奶瓶、婴儿推车等育儿专用品 | 儿童普通衣鞋归购物／服饰鞋包；药品归医疗健康／药品 | 纸尿裤、奶瓶、婴儿推车 |
| 托育 | 以看护为主的托育服务 | 明确的知识课程归课程培训，运动教学归运动健身 | 托育机构看护费 |

### 照护

范围：专门面向照护需要的非医院护理和日常陪护。不按被照顾者身份把其餐饮、住房、医药全部放进本组。

| 二级 | 包含 | 不包含及应归哪里 | 例子 |
|---|---|---|---|
| 护理 | 独立购买、明确以专业护理为内容的服务 | 医院诊疗套餐归门诊住院；医疗器械归医疗器械；普通陪伴归照护服务 | 独立上门护理服务 |
| 照护服务 | 生活照料、陪护、陪诊中的陪伴服务 | 诊疗费归门诊住院；独立专业护理归护理；普通保洁归家政洗护 | 生活陪护、独立陪诊服务费 |

### 税费与行政

范围：个人实际另行支付的税费及证件行政办理费。分类只描述账单性质，不替代计税规则；证券交易税费随投资事件，工资已经按税后到账记录时不再重复列支代扣税。

| 二级 | 包含 | 不包含及应归哪里 | 例子 |
|---|---|---|---|
| 个人税费 | 已核实由个人另行实际缴付的税费 | 证券交易税费走投资事件；商品标价内税费随商品，不强制拆分；工资已扣税不重复计 | 个人另外补缴的一笔税款 |
| 证件办理 | 身份、出入境等证件办理的行政收费 | 职业考试和认证归教育学习／考试认证；旅行机票归机票 | 护照办理费、证件补办费 |

## 6. 使用自己的分类口径

默认说明适用于内置目录。若修改分类的用途，建议同步写清新的包含、排除和例子，保持以后记账一致；仅改名字或图标不会自动改写用途说明，更不会重新归类历史流水。

新增自定义分类可以补充自己的说明；还没写时，指南显示“尚未填写分类说明”，不根据名称猜测定义。移动或合并分类仍需遵循历史、预算、导入规则的影响预览，不能由指南页面悄悄完成。
