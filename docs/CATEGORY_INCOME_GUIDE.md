# 使用指南：收入分类说明

本文是 **设置 → 使用指南** 中的收入分类文案，配合[分类使用指南](CATEGORY_GUIDE.md)和[正式分类目录](../IOS_CATEGORIES.md)使用。内容仅在使用指南中展示，不加入记账页面、分类选择面板或保存流程。本轮仅新增文档，未修改 App；指南入口及展示仍按后续开发安排实施。

覆盖现有 **5 个收入一级、10 个收入二级**，不新增分类。文中的语义 ID 供开发映射与审查，用户阅读时显示分类名称即可；语义 ID 对应既有分类 UUID，不随改名或说明文字变化。下列例子均为说明规则的合成情境，描述本账本的归类方式，不作为税务或收益性质认定。

## 一、先判断这笔钱是不是收入

收到钱时，先确认它是劳动、经营、利息、赠与等收入，还是自己账户间转账、往来款结算、报销回款或支出回收。分类看实际性质，不以付款人名称、支付平台或账单上的“转入”字样决定。

已有明确用途的普通收入选择对应二级；已确认是收入但没有合适细项时，才选择“其他明确收入”。性质还不清楚的流水保持待核对，不能为了完成分类自动放入“其他收入”。

一笔普通收支只选择一个二级。不要把同一实际到账重复记录到多个分类，也不要用同额新收入补偿已有转账、回收或投资记录。借还款本金和利息等业务组件沿用既有事件处理规则。

## 二、工作收入（employment）

**范围**：因受雇工作，或以个人身份提供时间、技能和劳务而取得的报酬。工资、奖金及个人兼职劳务分别记录；持续经营项目、店铺或出租取得的收款归经营收入。

| 二级分类及语义 ID | 包含 | 不包含及应归哪里 | 典型例子 |
|---|---|---|---|
| 工资（employment.salary） | 日常工资、薪金；随工资发放且属于劳动报酬的岗位津贴、餐补、交通补贴等。采用实际到账金额，不把工资条上未实际到账的项目再当现金收入。 | 单独发放并明确为绩效、年终等奖金的款项归工作收入／奖金；个人兼职报酬归兼职劳务；垫付后凭票收回的钱走报销回款；与劳动报酬无关的独立生活、助学补助归赠与补助／补助。 | 月工资实际到账 8,000 元，其中包含固定岗位津贴，这一笔归工资。 |
| 奖金（employment.bonus） | 因工作绩效、年度考核、项目贡献等获得，并以奖金性质单独支付的劳动奖励。 | 常规月薪和随薪固定津贴归工资；普通活动抽奖不是工作奖金，应先核实是否属于独立现金收入，再考虑其他明确收入；报销回款走报销。 | 公司另行发放年终奖 5,000 元，归奖金。 |
| 兼职劳务（employment.freelance） | 以个人身份提供劳务或专业技能取得的报酬，例如稿费、个人摄影接单、临时家教和临时协助工作。 | 自己经营店铺或业务项目的商品、服务收款归经营收入／经营所得；受雇岗位的常规工资归工资；替人垫付后收回的款项走报销或对应往来结算。 | 个人为他人完成一次摄影工作，收到约定劳务报酬 600 元，归兼职劳务。 |

工资和奖金合并为一笔实际到账时，本账本不要求普通流水拆单，默认按工资记录，并可在备注注明包含奖金；不再另记同额或部分重复的奖金收入。实际存在分别到账的记录时，分别按各笔性质分类。

## 三、经营收入（business）

**范围**：自己开展经营活动的收款，以及出租产生的租金收入。收入收款与相关成本分开记录，收款金额不能直接代表净利润；本分类不决定活动的法律或税务性质。

| 二级分类及语义 ID | 包含 | 不包含及应归哪里 | 典型例子 |
|---|---|---|---|
| 经营所得（business.earnings） | 按自己的经营项目、店铺或业务持续对外销售商品、提供服务取得的实际收款。归类依据是已确认的经营用途，不单靠金额或付款次数判断。 | 个人提供技能或临时劳务的报酬归工作收入／兼职劳务；出租租金归租金；借入经营资金走借入事件；出售个人旧物先判断是否属于已关联购买的回收；可退押金走往来款。 | 自己经营的小店售出商品并收到货款 300 元，归经营所得；相关进货成本不通过少记这笔收入来抵销。 |
| 租金（business.rent） | 已确认属于出租房屋、车位或其他物品使用权的实际租金收款。 | 租客交付的可退押金按往来款管理；代收代付、垫付返还按对应结算处理；出售房屋或其他资产不能按租金分类，需先核实事件性质。 | 收到当月房租 2,000 元，归租金；另收到可退押金 2,000 元，后者不记租金收入。 |

## 四、资金收益（interest）

**范围**：已实际收到、且已明确性质的存款利息和借出利息。只记录收益部分，不包括本金回流，也不替代投资交易和投资收益事件。

| 二级分类及语义 ID | 包含 | 不包含及应归哪里 | 典型例子 |
|---|---|---|---|
| 存款利息（interest.deposit） | 银行活期、定期等存款实际到账的利息。需要确认是存款利息，不能因为付款方是银行就归入这里。 | 存款本金转回按账户转账处理；借给他人取得的利息归借出利息；证券分红、交易收益等沿用投资事件；性质不明的理财到账先核实，不直接当作存款利息。 | 银行结息到账 12 元，归存款利息；同时到期转回的存款本金不重复记收入。 |
| 借出利息（interest.lending） | 自己借出资金后，实际收到并明确属于利息的部分。 | 收回借出本金走借出本金回收，减少待收；收到别人借给自己的本金走借入；自己支付的借款利息归支出／财务费用／借款利息；本金减免不靠此分类补差。 | 一次收回借出本金 1,000 元和利息 20 元，本金按往来结算，只有 20 元归借出利息。 |

## 五、赠与补助（benefits）

**范围**：无需提供商品或劳务作为对价、无需归还的现金赠与，以及已确认性质的独立补助。实际收到实物礼物时，不因估算物品价值而虚构现金收入。

| 二级分类及语义 ID | 包含 | 不包含及应归哪里 | 典型例子 |
|---|---|---|---|
| 收礼（benefits.gifts） | 他人自愿给予、无需归还的现金礼金、节日红包和生活资助等赠与。 | 亲友借款走借入；偿还垫付或借款走对应结算；自己的账户互转走转账；提供服务后收到的“红包”本质是报酬，归兼职劳务或经营所得；平台活动红包先核实是否为赠与、消费回收或独立奖励。 | 家人赠送生日红包 500 元，确认无需归还，也不是代付款返还，归收礼。 |
| 补助（benefits.allowance） | 与工资报酬、报销及借还款相区别的独立助学金、生活补助、困难补助等实际到账款项。 | 随工资发放且属于劳动报酬的岗位津贴等归工资；因工作表现获得的奖金归奖金；凭票返还垫付款走报销；亲友自愿赠与归收礼；保险理赔先核实具体业务性质，不一律归补助。 | 收到已核实性质的助学补助 1,000 元，既不是工资也不用于结清垫付款，归补助。 |

## 六、其他收入（income_other）

**范围**：已经确认属于普通收入，但现有其他二级均不适合的款项。它不是所有入账款项的兜底，也不是未知用途的完成状态。

| 二级分类及语义 ID | 包含 | 不包含及应归哪里 | 典型例子 |
|---|---|---|---|
| 其他明确收入（income_other.identified） | 已核实为独立现金收入、没有其他合适分类的款项；例如与购买、垫付和投资无关的普通活动现金奖励。用户出售开始记账前购入的个人旧物，明确选择按普通收入记录时，也可选此类。 | 自己账户互转、借入本金、收回借出本金、报销回款、已关联购买的退款及二手回收不属普通收入，走对应事件；证券分红和已实现收益走投资事件；优惠券、未提现积分不按面值虚构现金收入；复杂返现或理赔先核实，不自动归入此类。 | 记账前已购入的旧椅子售出 100 元，用户明确选择普通收入并选此类；无需强制补录椅子的原购买。 |

## 七、常见收入冲突

| 有争议的情况 | 判断与归属 | 避免的重复或误分 |
|---|---|---|
| 工资、奖金与“补贴” | 常规工资及劳动报酬型随薪津贴归工资；单独明确的绩效、年终劳动奖励归奖金；独立生活或助学补助归补助。 | 不能仅按付款备注中的“补贴”“奖励”两个词自动分类。 |
| 工资与奖金合并到账 | 普通流水保留一笔，默认归工资，可备注组成；实际分开到账才分别分类。 | 不在已有工资收入之外，再记一笔实际不存在的奖金到账。 |
| 兼职与经营 | 个人提供时间、技能和劳务归兼职劳务；以自己经营项目或店铺对外销售商品、服务归经营所得。同一业务按已确认性质保持一致。 | 不按单次金额大小、收款平台或偶然收款频次来回切换；经营收款也不直接视为净利润。 |
| 租金与押金 | 出租使用权的收入归租金；仍需退还的押金属于往来款。押金用途改变时先核实真实结算性质。 | 收到可退押金时不记租金，退还时也不因此再虚构消费。 |
| 借入、还本与利息 | 借入本金、收回借出本金均走往来；借出利息归资金收益／借出利息。借入减免沿用独立非现金事件。 | 收回本金 100 元和利息 5 元，普通收入只有 5 元，不能把 105 元全归收入。 |
| 报销与工资、补助 | 收回已垫付的款项走报销回款；无需结清垫付的劳动报酬或独立补助再按其性质选择收入分类。 | 报销回款不计普通收入，不释放消费预算。 |
| 退款与普通收入 | 能关联原购买的退款走支出回收。原流水保留原金额，详情记录回收额与净花费。 | 不新增普通收入，不改写原发生月份支出，也不释放原预算。 |
| 出售已在账本关联购买的个人旧物 | 关联原购买，走出售回收。 | 不因通过二手平台收款就自动当经营收入或其他收入。 |
| 出售开始记账前购入的个人旧物 | 可由用户手动选择普通收入及相应分类，例如其他明确收入。 | 不强制补录原购买，不自动生成物品或回收事件，不把所有二手出售都套用这一例外。 |
| 存款利息与投资收益 | 已确认的存款结息归存款利息；证券分红、已实现交易收益沿用投资事件进入投资分析。 | 卖出证券收回的本金不计普通收入，投资收益也不另记一次同额日常收入。 |
| 自己账户转入与余额补差 | 自己账户间划转按转账处理；期初与余额更正按既有独立事件处理。 | 不通过“其他收入”使账户余额看起来正确。 |
| 活动奖励、返现与优惠 | 工作奖励先看工资或奖金；独立现金活动奖励经核实后可归其他明确收入；明确属于原购买退回且能关联的款项走回收。消费返利、积分兑换等性质不清时继续核实。 | 不把“奖励”“返现”自动全归收入，不把优惠券、未提现积分或支付时已抵扣的优惠额再记一次现金收入。 |
| 保险理赔与补助、回收 | 先区分是否与已有垫付相关，还是独立赔付款；复杂理赔仍需确认业务性质，遵循正式设计的待扩展边界。 | 不自动归补助、其他收入或保费，也不在本指南中虚构尚未确定的理赔处理功能。 |
| 收礼、服务红包与亲友转账 | 无需归还的真实现金赠与归收礼；服务对价归兼职劳务或经营所得；借还、代付回款走各自结算。 | 不凭“红包”样式、人名或亲友关系推断赠与。 |

对尚不能确定的交易，先核实对应事实，再选择事件性质与分类。本指南不会把未知款项自动转成收入，也不会改变现有退款、预算、报销、借还款和投资口径。
