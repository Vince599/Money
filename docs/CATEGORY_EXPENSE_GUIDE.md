# 支出分类使用指南

本指南解释每个支出分类“放什么、不放什么”，供设置 → 使用指南 → 分类说明查阅。选择前可先阅读[分类总则与争议场景](CATEGORY_GUIDE.md)；分类名称、层级与默认图标见[两级分类附录](../IOS_CATEGORIES.md)。

先判断钱的性质，再判断用途。自己账户之间转账、储值充值、可退押金、借还本金、报销垫付等使用对应事件，不因为付款了就选择支出分类。实际消费才按下表归类。已关联购买的退款、出售回收使用支出回收事件，保留原始支出，不释放原预算。

商户、购物平台、付款账户、线上线下、购买频率和价格不决定分类。专用分类优先于笼统的“购物”或“其他”；明确赠礼目的的物品优先归礼物。给家庭成员购买普通生活用品仍按实际用途记录，成员用主体表达。

以下覆盖基础目录的 **15 个支出一级、70 个支出二级**。每笔只选一个分类；组合消费优先使用已经明确的成套归类规则，其余按金额占比最高的已知子项归类，金额相同时按主要购买目的，备注补充内容，不强制拆单。名称前的语义 ID 用于与分类附录对照。

## 1. 餐饮 `food`

**范围：** 供人食用的餐食、饮料、零食、水果和做饭原料。

**排除：** 食物制作与盛放工具、家电不属于餐饮；为赠送而购买的食品归人情往来／礼物；宠物模板启用后，宠物食品归宠物／食品。旅行或聚会中的餐饮仍归本类。

|---|---|---|---|
| `food.meals` 正餐 | 堂食及没有明确外卖性质的普通餐食，包括早餐、简餐和食堂用餐。 | 明确外卖餐食 → 餐饮／外卖；单独饮品 → 餐饮／饮品；单独零食 → 餐饮／零食。 | 饭馆晚餐、单位食堂午餐、早餐店包子豆浆套餐。 |
| `food.delivery` 外卖 | 明确通过外卖方式购买的餐食，订单内附带的小额配菜、饮品和配送费可随餐食记录。 | 单独外卖咖啡、奶茶 → 餐饮／饮品；买菜配送 → 餐饮／食材；独立跑腿服务 → 生活服务／快递跑腿。 | 外卖午饭、披萨外送、含配送费的盖饭订单。 |
| `food.drinks` 饮品 | 直接饮用的咖啡、茶饮、饮用水、果汁和酒水，购买方式不改变归属。 | 咖啡豆、干茶叶等冲泡原料 → 餐饮／食材；杯子 → 购物／厨具餐具；咖啡机 → 购物／家用电器。 | 外卖咖啡、奶茶、瓶装水、单独购买的啤酒。 |
| `food.snacks` 零食 | 正餐之外单独购买的包装小吃、糖果、糕点和休闲食品。 | 新鲜水果 → 餐饮／水果；普通餐食 → 餐饮／正餐或外卖；明确赠送的零食礼盒 → 人情往来／礼物。 | 薯片、巧克力、饼干、追剧时吃的坚果。 |

| `food.fruit` 水果 | 新鲜水果和以鲜果为主的果切。 | 果汁 → 餐饮／饮品；果干、果脯 → 餐饮／零食；送人的水果礼盒 → 人情往来／礼物。 | 苹果、香蕉、西瓜、即食鲜果切。 |

## 2. 交通 `transport`

**范围：** 人员出行、车辆使用及养护费用，不按通勤、旅行或探亲目的重复建类。

**排除：** 酒店归居住／住宿，车险归保险／车辆保险，交通卡充值归储值转账，可退押金归往来款。车辆购置不直接当作车辆养护；共享单车和租车可按分类附录启用骑行租车扩展。

|---|---|---|---|

| `transport.train` 火车 | 高铁、动车、普通铁路客运车票及同单附带的必要票务费用。 | 地铁 → 交通／公交地铁；机票 → 交通／机票；酒店 → 居住／住宿。 | 高铁二等座、动车票、卧铺火车票。 |

| `transport.tolls` 路桥费 | 使用收费公路、桥梁等道路设施的实际通行费用。 | ETC 预充值 → 储值转账；停车 → 交通／停车；燃油 → 交通／燃油充电。 | 高速通行费、收费桥梁通行费、ETC 实际扣费。 |

## 3. 居住 `housing`

**范围：** 居住空间的租用、临时住宿、公共维护、能源、家具布置和房屋修缮。

**排除：** 家用电器归购物，网络服务归通信，日常保洁归生活服务。购房、住房贷款本金和可退押金需按资产、债务或往来款性质处理。

| 语义 ID 与分类名 | 包含 | 不包含 → 目标分类或事件 | 典型例子 |
|---|---|---|---|
| `housing.rent` 房租 | 为持续租住住房支付的租金。 | 可退租房押金 → 往来款；酒店民宿 → 居住／住宿；住房贷款本金 → 债务本金结算；借款利息 → 财务费用／借款利息。 | 月租、季租、按合同支付的住房租金。 |

| `housing.property` 物业 | 住宅物业管理和公共区域维护服务费用。 | 单独停车费 → 交通／停车；水电燃气 → 居住／水电燃气；户内保洁 → 生活服务／家政洗护。 | 小区物业费、住宅公共维护服务费。 |
| `housing.accommodation` 住宿 | 酒店、民宿、旅馆等临时住宿费用。 | 长期租住房租 → 居住／房租；可退住宿押金 → 往来款；单独支付的餐饮 → 餐饮对应细项。 | 旅行酒店、出游民宿、自费临时住宿。 |

## 4. 购物 `shopping`

**范围：** 日常生活中的通用品，包括衣鞋包、日用品、美妆、厨具餐具和家用电器；只有没有更合适专用类别的商品才进入其他购物。

**排除：** 数码硬件、图书、运动器材、家具等分别进入专用类别；服务不能因为在购物平台付款就记为购物。明确赠送给他人的物品归人情往来／礼物。

| 语义 ID 与分类名 | 包含 | 不包含 → 目标分类或事件 | 典型例子 |
|---|---|---|---|
| `shopping.household` 日用品 | 日常家庭使用的纸品、清洁用品和通用生活消耗品。 | 护肤彩妆 → 购物／美妆护理；家政洗衣服务 → 生活服务／家政洗护；家具家纺 → 居住／家居家具。 | 纸巾、垃圾袋、洗衣液、清洁剂。 |
| `shopping.clothing` 服饰鞋包 | 衣服、鞋、包及普通配饰按物品性质归类，无论用于运动、旅行、通勤还是休闲。 | 健身房及运动课程 → 休闲运动／运动健身；哑铃、瑜伽垫、球拍 → 休闲运动／运动健身；智能手表 → 数码设备／智能与穿戴。 | 运动衣、跑鞋、泳衣、徒步鞋、运动包、日常服装。 |

| `shopping.other` 其他购物 | 用途已经明确、确实购买了商品，且基础或已启用的专用分类都不适合的购物，包含通用办公文具。 | 图书 → 教育学习／图书资料；运动器材 → 休闲运动／运动健身；兴趣材料 → 休闲运动／兴趣爱好；用途未知 → 待分类。 | 办公订书机、文件夹等通用文具；文具采购经常出现时可自建细项。 |

**排除：** 软件和云服务归数字服务，游戏内容归休闲运动／游戏，课程归教育学习。智能家电整机仍归购物／家用电器，专门医疗监测器械归医疗健康／医疗器械，硬件维修归生活服务／维修服务。

## 6. 通信 `communications`

**范围：** 通话、流量和网络接入等通信服务实际消费。

**排除：** 充值先转入储值账户，实际扣费才记消费；手机、路由器是硬件，云盘是数字服务。运营商代扣的影音会员仍归其实际用途。

| 语义 ID 与分类名 | 包含 | 不包含 → 目标分类或事件 | 典型例子 |
|---|---|---|---|
| `communications.mobile` 手机话费 | 手机基础套餐及普通通话、短信服务的实际扣费。 | 话费充值 → 储值转账；单独购买额外流量包 → 通信／通信增值服务；手机整机 → 数码设备／手机平板。 | 手机月套餐费、超出套餐的普通通话费。 |
| `communications.broadband` 宽带 | 家庭或个人固定网络接入服务费用。 | 路由器 → 数码设备／网络与存储；云存储 → 数字服务／云服务与存储；独立移动流量包 → 通信／通信增值服务。 | 家庭宽带月费、宽带年费、宽带安装服务费。 |

## 7. 医疗健康 `health`

**范围：** 就医诊疗、独立检查体检、药品和专用医疗护理器械。

**排除：** 健身锻炼归休闲运动，保费归保险，日常护肤及美容服务按对应购物或生活服务分类；不能仅因商家宣传“健康”就归本类。

| `health.equipment` 医疗器械 | 专门用于健康监测、治疗辅助和医疗护理的器械。 | 普通智能手表 → 数码设备／智能与穿戴；哑铃、瑜伽垫 → 休闲运动／运动健身；家用清洁或护理电器 → 购物／家用电器。 | 血压计、血糖仪、医用体温计、医疗护理设备。 |

## 8. 教育学习 `education`

**排除：** 运动课程、健身私教归休闲运动／运动健身；持续更新的资讯会员归数字服务／内容资讯；学习用电脑仍归数码设备。

|---|---|---|---|
| `leisure.entertainment` 文娱活动 | 以观看表演、观看比赛或参与娱乐为主要内容的活动费用。 | 线上影音会员 → 数字服务／影音会员；景区博物馆参观 → 休闲运动／景点门票；单独餐饮 → 餐饮对应细项。 | 电影院电影票、演唱会、戏剧、体育赛事门票、KTV、密室活动。 |

| `social.donations` 公益捐赠 | 明确用于公益、慈善目的且无需收回的捐赠。 | 亲友个人礼金 → 人情往来／礼金红包；购买自用商品 → 按商品用途；用途未知的对外转账 → 待核对事件性质。 | 公益项目捐款、慈善捐赠。 |

**排除：** 周期付款不是本类的判断条件。房租、健身年卡、宽带各归实际用途，游戏归休闲运动，图书和课程归教育学习，硬件归数码设备。

## 14. 财务费用 `financial`

**范围：** 借款利息、借款相关服务费，以及普通账户和支付服务收取的手续费。

**排除：** 本金是转账或债务结算，证券交易费用是投资事件的费用组件；带“费”字的物业、水电、服务付款仍按实际用途分类。

| 语义 ID 与分类名 | 包含 | 不包含 → 目标分类或事件 | 典型例子 |
|---|---|---|---|
| `financial.interest` 借款利息 | 使用借入资金或信用消费产生的利息，只记录利息部分。 | 贷款或信用卡本金归还 → 债务本金结算或还款转账；借款服务费 → 财务费用／借款服务费；收到借出利息 → 资金收益／借出利息。 | 房贷利息、消费贷款利息、信用消费分期利息。 |
| `financial.payment` 账户与支付手续费 | 普通账户维护、转账、提现和支付过程中单独收取的手续费。 | 借款专属服务费 → 财务费用／借款服务费；证券交易税费 → 投资费用组件；商品运费 → 随商品或生活服务／快递跑腿。 | 提现手续费、转账手续费、普通账户管理费。 |

## 15. 其他支出 `other`

**范围：** 已核实为个人消费或支出、用途已知，但基础及已启用分类都不适合的费用。

**排除：** 不能把用途未知、事件性质不明或尚未核对的流水塞进本类；转账、往来款、投资、余额更正和借出损失也不是“其他消费”。

| 语义 ID 与分类名 | 包含 | 不包含 → 目标分类或事件 | 典型例子 |
|---|---|---|---|
| `other.identified` 其他明确支出 | 确认用途后仍没有合适专用类别的支出，并可用备注说明具体事项。 | 用途未知 → 待分类；有专用类别 → 对应分类；转账、借还本金、报销垫付 → 对应事件；借出损失 → 损失事件。 | 未启用行政扩展时已核实的证件办理费；反复出现的用途可新建专用分类。 |

有两个类别看起来都合适时，优先沿用本指南中的明确边界并保持前后一致；分类可自定义，但不要让同一种衣物、图书或设备因为商户、场景、付款方式不同而反复换类。
